# 쇼미더머니 나라 — GitHub Pages + Firebase 설치 가이드

처음 하는 분 기준으로 클릭 하나하나 적었습니다. 위에서부터 순서대로 따라 하세요.
전체 소요 시간은 30~40분 정도이고, **비용은 들지 않습니다.**

---

## 0. 무엇이 바뀌었나요?

| 예전 (구글 앱스 스크립트) | 지금 |
|---|---|
| 화면: 앱스 스크립트 웹앱 | 화면: **GitHub Pages** (무료 웹사이트 호스팅) |
| 데이터: 구글 시트 | 데이터: **Firebase Firestore** (구글의 무료 데이터베이스) |
| 서버 코드: Code.gs | **Code.gs를 그대로 사용**합니다 (브라우저에서 실행) |

화면 디자인과 기능은 그대로입니다. 바뀐 점은 다음과 같습니다.
- 앱스 스크립트보다 **훨씬 빠릅니다**(보통 1초 안쪽).
- 학생 여러 명이 동시에 눌러도 데이터가 꼬이지 않게 처리됩니다.
- 선생님 비밀번호와 학급 관리자 비밀번호는 **암호화해서** 저장됩니다.

### 폴더 구성

```
📁 site                 ← 이 폴더 "안의 파일들"을 GitHub에 올립니다
   index.html           화면 (예전 Index.html)
   style.css            디자인 (예전 style.html)
   app.js               화면 동작 코드 (예전 JavaScript.html)
   Code.gs              서버 코드 (예전 Code.gs와 같은 파일)
   gas-bridge.js        구글 시트 대신 Firebase를 쓰게 해 주는 연결 코드 (고칠 필요 없음)
   firebase-config.js   ★ 4단계에서 내 Firebase 정보를 붙여넣을 파일
   import.html          예전 구글 시트 데이터를 옮길 때 쓰는 페이지
   .nojekyll            GitHub Pages용 빈 파일 (그대로 두세요)
📄 firestore.rules        6단계에서 복사해 붙여넣을 보안 규칙
📄 기존데이터_내보내기.gs  9단계(예전 데이터 옮기기)에서 사용
📄 설치가이드.md           지금 보고 있는 파일
```

> 💡 **파일 여는 법:** `.js`, `.rules`, `.gs` 파일은 마우스 오른쪽 버튼 → **연결 프로그램** → **메모장**으로 열면 됩니다.

## 1. GitHub 가입하기

1. https://github.com 에 접속합니다.
2. 오른쪽 위 **Sign up**을 누릅니다.
3. 이메일, 비밀번호, 사용자 이름(Username)을 입력합니다.
   - 사용자 이름은 사이트 주소에 들어갑니다. 예를 들어 `smtm-teacher`로 정하면 주소는 `https://smtm-teacher.github.io/...`가 됩니다.
4. 이메일로 온 인증 코드를 입력하면 가입이 끝납니다.

---

## 2. Firebase 프로젝트 만들기

1. https://console.firebase.google.com 에 접속해 **구글 계정으로 로그인**합니다.
2. **"Firebase 프로젝트 만들기"**(또는 "프로젝트 추가")를 누릅니다.
3. 프로젝트 이름을 입력합니다. 예: `showmethemoney` → **계속**
4. "Gemini 사용", "Google 애널리틱스" 같은 질문이 나오면 **모두 끄고** 계속 진행합니다(나중에 켤 수 있음).
5. **프로젝트 만들기**를 누르고 30초쯤 기다린 뒤 **계속**을 누릅니다.

---

## 3. 익명 로그인 켜기 (Authentication)

학생과 선생님이 사이트에 들어오면 보이지 않게 "익명 로그인"이 되고, 그래야만 데이터를 읽고 쓸 수 있습니다. 아무나 데이터베이스를 건드리지 못하게 막는 장치입니다.

1. 왼쪽 메뉴 **빌드(Build)** → **Authentication**을 누릅니다.
2. **시작하기**를 누릅니다.
3. **로그인 방법(Sign-in method)** 탭에서 목록 중 **익명(Anonymous)**을 누릅니다.
4. **사용 설정(Enable)** 스위치를 켜고 **저장**을 누릅니다.

---

## 4. 웹 앱 등록하고 설정값 복사하기

1. 왼쪽 위 **⚙️ 톱니바퀴** → **프로젝트 설정**을 누릅니다.
2. 아래쪽 **"내 앱"** 칸에서 **`</>`** 모양(웹) 아이콘을 누릅니다.
3. 앱 닉네임에 `smtm-web`처럼 아무 이름이나 입력합니다.
   - "Firebase 호스팅도 설정" 체크박스는 **체크하지 마세요.**
4. **앱 등록**을 누르면 아래처럼 생긴 코드가 나옵니다.

   ```js
   const firebaseConfig = {
     apiKey: "AIzaSyB....",
     authDomain: "showmethemoney-xxxx.firebaseapp.com",
     projectId: "showmethemoney-xxxx",
     storageBucket: "showmethemoney-xxxx.firebasestorage.app",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef..."
   };
   ```

5. `site` 폴더의 **`firebase-config.js`**를 메모장으로 열고, 따옴표 안의 `여기에_..._붙여넣기` 부분을 위에서 나온 값으로 하나씩 바꿉니다.

   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "AIzaSyB....",
     authDomain: "showmethemoney-xxxx.firebaseapp.com",
     projectId: "showmethemoney-xxxx",
     storageBucket: "showmethemoney-xxxx.firebasestorage.app",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef..."
   };
   ```

   ⚠️ 첫 줄 `window.FIREBASE_CONFIG = {`는 **그대로 두세요.** `const firebaseConfig`로 바꾸면 안 됩니다.

6. 저장(Ctrl+S)하고 Firebase 화면에서 **콘솔로 이동**을 누릅니다.

> 이 값들은 웹사이트에 공개되어도 괜찮도록 만들어진 값입니다. 데이터는 3단계와 6단계의 설정이 지켜 줍니다.

---

## 5. Firestore 데이터베이스 만들기

1. 왼쪽 메뉴 **빌드** → **Firestore Database**를 누릅니다.
2. **데이터베이스 만들기**를 누릅니다.
3. 위치(Location)는 **`asia-northeast3 (Seoul)`**을 고르고 **다음**을 누릅니다.
   - ⚠️ 위치는 나중에 바꿀 수 없습니다.
4. **프로덕션 모드에서 시작**을 고르고 **만들기**를 누릅니다.

---

## 6. 보안 규칙 넣기

1. Firestore 화면 위쪽에서 **규칙(Rules)** 탭을 누릅니다.
2. 편집창의 내용을 **전부 지웁니다**(Ctrl+A → Delete).
3. `firestore.rules` 파일을 메모장으로 열어 **전부 복사**(Ctrl+A → Ctrl+C)한 뒤 편집창에 붙여넣습니다(Ctrl+V).

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /spaces/{space}/sheets/{sheet} {
         allow read, write: if request.auth != null;
       }
     }
   }
   ```

4. **게시(Publish)**를 누릅니다.

---

## 7. GitHub에 파일 올리기

1. https://github.com 에 로그인한 뒤 오른쪽 위 **＋** → **New repository**를 누릅니다.
2. 다음처럼 입력합니다.
   - **Repository name:** `showmethemoney` (영어로. 사이트 주소에 들어갑니다)
   - **Public** 선택. 무료 GitHub Pages는 공개 저장소에서만 됩니다.
   - 나머지는 그대로 두고 **Create repository**를 누릅니다.
3. 다음 화면에서 **"uploading an existing file"** 링크를 누릅니다.
4. 내 컴퓨터에서 **`site` 폴더를 연 다음**, 그 **안의 파일 전부**(index.html, style.css, app.js, Code.gs, gas-bridge.js, firebase-config.js, import.html, .nojekyll)를 선택해 브라우저 화면으로 끌어다 놓습니다.
   - ⚠️ `site` 폴더 자체를 끌어다 놓으면 주소가 달라집니다. **폴더 안의 파일들**을 놓으세요.
   - 4단계에서 수정한 `firebase-config.js`가 들어갔는지 꼭 확인하세요.
5. 아래 **Commit changes** 버튼을 누릅니다.

## 8. GitHub Pages 켜기 (사이트 공개)

1. 저장소 화면 위쪽에서 **⚙️ Settings**를 누릅니다.
2. 왼쪽 메뉴에서 **Pages**를 누릅니다.
3. **Build and deployment** → **Source**를 **Deploy from a branch**로 둡니다.
4. **Branch**에서 `main`, 폴더는 `/ (root)`를 고르고 **Save**를 누릅니다.
5. 1~3분 기다린 뒤 새로고침하면 위쪽에 이렇게 나옵니다.
   **"Your site is live at `https://사용자이름.github.io/showmethemoney/`"**
6. 그 주소가 **우리 반 사이트 주소**입니다. 학생들에게 이 주소를 알려 주면 됩니다.

### 8-1. Firebase에 내 사이트 주소 등록하기 (권장)

1. Firebase 콘솔 → **Authentication** → **설정(Settings)** 탭 → **승인된 도메인(Authorized domains)**으로 갑니다.
2. **도메인 추가**를 누르고 `사용자이름.github.io`를 입력합니다(https나 뒤쪽 경로 없이).

### 8-2. 잘 되는지 확인하기

1. 사이트 주소로 접속합니다.
2. 화면 아래에 노란 띠(**"🧪 로컬 테스트 모드"**)가 **보이지 않아야** 정상입니다.
   - 노란 띠가 보이면 `firebase-config.js`가 제대로 수정되지 않은 것입니다. 4단계를 다시 확인하세요.
3. **선생님 회원가입** → **로그인** → **학급 개설** → 학생 추가까지 해 봅니다.
4. Firebase 콘솔 → Firestore Database → **데이터** 탭에 `spaces`가 생겼으면 성공입니다. 🎉

> ⚠️ 새 사이트는 **빈 데이터베이스**로 시작합니다. 선생님 계정은 새로 가입해야 합니다. 예전 데이터를 그대로 가져오고 싶다면 9단계를 따라 하세요.

## 9. (선택) 예전 구글 시트 데이터 옮기기

### 9-1. 구글 시트에서 내보내기
1. 예전 **앱스 스크립트 편집기**를 엽니다(구글 시트 → 확장 프로그램 → Apps Script).
2. 왼쪽 **파일 옆 ＋** → **스크립트**를 누르고 이름을 `Export`로 정합니다.
3. 안의 내용을 지우고 `기존데이터_내보내기.gs` 파일 내용을 전부 붙여넣은 뒤 **저장**(Ctrl+S)합니다.
4. 위쪽 함수 선택 칸에서 **`exportForFirebase`**를 고르고 **▶ 실행**을 누릅니다.
5. "승인 필요" 창이 뜨면 **권한 검토** → 내 계정 선택 → (경고 화면이 나오면) **고급** → **...(으)로 이동** → **허용**을 누릅니다.
6. 아래 **실행 로그**에 `https://drive.google.com/...` 주소가 나옵니다. 그 주소로 들어가 **다운로드**합니다(`.json` 파일).

### 9-2. 새 사이트로 가져오기
1. 브라우저 주소창에 `https://사용자이름.github.io/showmethemoney/import.html`을 입력해 들어갑니다.
2. 위쪽에 **"✅ Firebase에 연결된 상태입니다"**가 보이는지 확인합니다.
3. **파일 선택**에서 다운로드한 `.json` 파일을 고릅니다. 표에 시트별 행 수가 나옵니다.
4. **가져오기**를 누르고 "🎉 모두 완료" 메시지가 나올 때까지 기다립니다.
5. 사이트에서 **예전 선생님 계정 그대로** 로그인되는지 확인합니다.

### 9-3. 정리
- 옮기기가 끝나면 GitHub 저장소에서 **`import.html`을 삭제**하세요. 파일을 누름 → 오른쪽 위 **⋯** → **Delete file** → **Commit changes** 순서입니다. 다른 사람이 실수로 데이터를 덮어쓰지 못하게 하기 위해서입니다.

## 10. 나중에 코드를 고치고 싶을 때

- **GitHub 웹에서 바로 고치기:** 저장소에서 파일 클릭 → 오른쪽 위 **✏️ 연필** 아이콘 → 수정 → **Commit changes**를 누릅니다. 1~2분 뒤 사이트에 반영됩니다.
- 반영된 것 같지 않으면 사이트에서 **Ctrl + F5**(강력 새로고침)를 누르세요.
- **Code.gs**는 앱스 스크립트에서 쓰던 방식 그대로 고치면 됩니다. 새 함수를 추가해도 화면에서 `google.script.run.새함수(...)`로 바로 부를 수 있습니다.
- **고쳐야 하는 경우가 딱 두 가지 있습니다.** 이때만 `gas-bridge.js` 위쪽을 고치세요.
  1. Code.gs에 **첫 번째 인자가 학급코드가 아닌** 새 함수를 만들 때 → `NO_CLASS_FNS`에 함수 이름을 추가합니다.
  2. Teachers·Classes처럼 **모든 학급이 함께 쓰는** 새 시트를 만들 때 → `GLOBAL_SHEETS`에 시트 이름을 추가합니다.

## 11. 꼭 알아 둘 점

**무료 사용량** (Firebase Spark 요금제, 카드 등록 없음)
- 하루 읽기 5만 회, 쓰기 2만 회, 저장 공간 1GB까지 무료입니다. 한두 학급이 쓰기에는 넉넉합니다.
- 한도를 넘으면 돈이 청구되지 않고 **그날 자정(미국 태평양 시간, 한국 시간 오후 4~5시)까지 멈춥니다.**

**보안**
- 데이터베이스는 **사이트에 접속한 사람만** 읽고 쓸 수 있습니다.
- 예전 앱스 스크립트와 달리 계산이 **학생 브라우저에서** 일어납니다. 그래서 컴퓨터를 아주 잘 아는 학생이 개발자 도구로 데이터를 조작하는 것이 이론상 가능합니다. 교실 활동용으로는 충분하지만, 이 부분까지 완벽히 막으려면 Firebase 유료(Blaze) 요금제의 Cloud Functions가 필요합니다.
- GitHub 저장소가 공개라서 **코드는 누구나 볼 수 있습니다.** 코드 안에 비밀번호 같은 개인정보를 적지 마세요.
- 선생님 비밀번호는 암호화되어 저장되지만, 다른 중요한 사이트와 **같은 비밀번호는 쓰지 마세요.**

**데이터 백업**
- Firebase 콘솔 → Firestore Database → 데이터 탭에서 언제든 데이터를 볼 수 있습니다.

## 12. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| 화면 아래 노란 "로컬 테스트 모드" 띠가 보임 | `firebase-config.js`의 값이 비어 있습니다. 4단계를 다시 하고 파일을 GitHub에 다시 올리세요. |
| "Firebase 로그인 실패" 알림 | 3단계(익명 로그인 사용 설정)를 확인하세요. |
| "Firebase 권한 오류" 알림 | 6단계 보안 규칙을 붙여넣고 **게시**까지 눌렀는지 확인하세요. |
| "Code.gs 파일을 찾을 수 없습니다" | GitHub에 `Code.gs`가 올라가 있는지, 이름의 대소문자(C 대문자, gs 소문자)가 맞는지 확인하세요. |
| 사이트 주소가 404 | 8단계 후 몇 분 더 기다리세요. `index.html`이 저장소 맨 바깥(폴더 안이 아니라)에 있는지 확인하세요. |
| 수정했는데 안 바뀜 | 1~2분 기다린 뒤 Ctrl+F5를 누르세요. |
| 사이트 관리자 비밀번호(홈페이지 이름 변경용)를 잊어버림 | Firebase 콘솔 → Firestore Database → 데이터 → `spaces` → `global` → `sheets` → **`SiteSettings` 문서 삭제**. 이름이 '쇼미더머니 나라'로 돌아가고, 다음에 이름을 바꿀 때 비밀번호를 새로 정할 수 있습니다. |
| "현재 처리량이 많습니다" | 여러 명이 동시에 같은 작업을 할 때 생길 수 있습니다. 2~3초 뒤 다시 누르면 됩니다. |

> 🔍 그 밖의 오류는 사이트에서 **F12** → **Console** 탭에 빨간 글씨로 자세한 내용이 나옵니다. 그 내용을 캡처해서 물어보세요.
